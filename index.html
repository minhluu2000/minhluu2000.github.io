02

Papers

Also published as Luu Danh Minh

  1. DVCon U.S. 2026

    ConnChecker: Automated Root-Cause Analysis for Formal Connectivity Check via Graph

    Do Ngoc Tiep, Nguyen Linh Anh, Luu Danh Minh

    Finds the root cause of formal connectivity failures using a graph of the design. Cuts debug time by up to 80% on two industrial SoCs.

    arXiv ↗

  2. DVCon U.S. 2026

    Saarthi for AGI: Towards Domain-Specific General Intelligence for Formal Verification

    Aman Kumar, Deepak Narayan Gadde, Luu Danh Minh, Vaisakh Naduvodi Viswambharan, Keerthan Kopparam Radhakrishna, Sivaram Pothireddypalli

    Adds a rulebook, a specification grammar, and GraphRAG to the Saarthi multi-agent framework. Assertion accuracy improves by about 70%.

    arXiv ↗

  3. MLCAD 2025

    VCDiag: Classifying Erroneous Waveforms for Failure Triage Acceleration

    Minh Luu, Surya Jasper, Khoi Le, Evan Pan, Michael Quinn, Aakash Tyagi, Jiang Hu

    Classifies failing simulation waveforms to find the buggy RTL module. Reaches over 94% top-3 accuracy and shrinks raw VCD data by over 120×.

    arXiv ↗ Code ↗ Designs ↗ Dataset ↗

  4. MLCAD 2025

    BugGen: A Self-Correcting Multi-Agent LLM Pipeline for Realistic RTL Bug Synthesis

    Surya Jasper, Minh Luu, Evan Pan, Aakash Tyagi, Michael Quinn, Jiang Hu, David Kebo Houngninou

    Uses LLM agents to create realistic RTL bugs. Produced 500 bugs at 94% functional accuracy and found 104 bugs that OpenTitan regressions missed.

    arXiv ↗ Code ↗
